## 📖 Overview

**PhytoPulse AI** is an AI-powered Smart Farming Assistant that combines IoT sensor data, machine learning, and real-time decision-making to help farmers optimize irrigation, monitor plant health, and respond to environmental conditions — all from a single, beautiful dashboard.

The system follows the **SENSE → ANALYZE → DECIDE → ACT** pipeline:

```
🌡️ SENSE          🧠 ANALYZE         ⚡ DECIDE          💧 ACT
─────────────     ──────────────     ───────────────    ──────────────
Soil Moisture  →  AI Plant Health →  Irrigation      →  Pump Control
Temperature       Analysis           Decision Engine     Alerts & Logs
Humidity          Trend Analysis     Risk Assessment     Notifications
Rain Detection    Anomaly Detection  Weather Logic       OLED Display
```

> **⚠️ This is a complete software simulation.** No physical hardware (ESP32, sensors, pumps) is required. All sensor data is generated by the built-in simulation engine. When real hardware is connected, it communicates via the `/api/devices/sensor-data` REST endpoint.

### 🌡️ Live Sensors
- Real-time data from 4 virtual sensors (soil moisture, temperature, humidity, rain)
- Visual progress bars and trend sparklines
- Last-update timestamp with live indicator dot

### 🤖 Plant Health AI
- Upload any crop image for AI analysis (no external ML model needed!)
- 4 built-in demo samples: Healthy Crop, Dry/Stressed Crop, Blight Detected, Optimal Growth
- Diagnostic report: health score, detected conditions, recommendations
- Analysis history log

### 💧 Irrigation Control
- Manual pump ON/OFF override
- Auto Mode: decision engine runs every 30 seconds
- Adjustable soil moisture threshold (10%–60%)
- Irrigation event history with duration and trigger reason

### 🚨 Alerts
- Severity-based alerts: CRITICAL, WARNING, INFO
- Filter by severity or unread status
- Mark individual or all alerts as read

### 📊 Analytics

- 4 interactive charts: soil moisture trend, temperature, humidity, plant health history

### Step 1: Database Setup

Open MySQL CLI and run:

```sql
CREATE DATABASE IF NOT EXISTS phytopulse_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Then apply the schema and seed data:

```powershell
# Windows PowerShell (use this — NOT the < redirect operator)
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
$pass  = "YOUR_MYSQL_PASSWORD"
$db    = "phytopulse_db"

Get-Content "database\schema.sql" -Raw | & $mysql -u root -p"$pass" $db
Get-Content "database\seed.sql"   -Raw | & $mysql -u root -p"$pass" $db
```

```bash
# Linux / macOS / Git Bash
mysql -u root -p phytopulse_db < database/schema.sql
mysql -u root -p phytopulse_db < database/seed.sql
```

```powershell
cd "phytopulse-ai\backend"
```

## 🔧 Irrigation Decision Engine Logic

```python
def make_decision(soil_moisture, temperature, humidity, rain_detected, threshold):

    # Rule 1: Rain override (highest priority)
    if rain_detected:
        return Decision(action=PREVENT, pump=OFF,
                        reason="Rain detected — irrigation prevented.")

    # Rule 2: Low moisture → irrigate
    if soil_moisture < threshold:
        priority = HIGH if (soil_moisture < 15 or temperature > 38) else MEDIUM
        return Decision(action=IRRIGATE, pump=ON,
                        reason=f"Soil moisture {moisture}% below threshold {threshold}%",
                        priority=priority)

    # Rule 3: Sufficient moisture → standby
    return Decision(action=STANDBY, pump=OFF,
                    reason="Soil moisture sufficient.")
```

The engine runs automatically every 30 seconds in Auto Mode. It also de-duplicates alerts — no duplicate alert is created within a 5-minute window for the same alert type.

## 🤖 Plant Health AI

The plant health analyzer uses **pure Python + Pillow** — no external ML model or internet connection required.

**Analysis pipeline:**
1. **Filename heuristic** — keywords like `dry`, `blight`, `healthy`, `optimal` in the filename boost diagnosis confidence
2. **Pixel RGB analysis** — measures green channel dominance vs red/yellow channels
3. **Color ratio thresholds** — determines health category: Healthy / Stressed / Disease Detected
4. **Recommendations** — generated from rule lookup table based on detected conditions

**Output:**
```json
{
  "health_score": 78,
  "status": "Healthy",
  "conditions": ["Good chlorophyll content", "Adequate moisture"],
  "recommendations": ["Continue current irrigation schedule"],
  "confidence": 0.82
}
```

## 🔮 Future Hardware Integration

When ESP32 hardware is available, integration requires minimal changes:

### ESP32-S3 Firmware

Flash the Arduino code from the **Devices** page (Arduino Code tab) to your ESP32-S3. Configure:

```cpp
const char* WIFI_SSID     = "YOUR_WIFI";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
const char* SERVER_URL    = "http://YOUR_SERVER_IP:5000";
const char* DEVICE_ID     = "ESP32_FIELD_01";
```

The firmware:
1. Reads sensors (soil moisture, DHT22, rain sensor) every 30 seconds
2. POSTs data to `/api/devices/sensor-data`
3. Polls `/api/devices/pump` for pump command
4. Activates relay module accordingly
5. Displays status on OLED
6. Triggers buzzer on CRITICAL alerts

### Required Connections (ESP32-S3)

| Sensor | ESP32 Pin |
|--------|-----------|
| Soil Moisture (analog) | GPIO 34 |
| DHT22 Data | GPIO 4 |
| Rain Sensor (digital) | GPIO 35 |
| Relay Module | GPIO 26 |
| OLED SDA | GPIO 21 |
| OLED SCL | GPIO 22 |
| Buzzer | GPIO 27 |

### ESP32-CAM

- Captures plant images every 15 minutes
- POSTs to `/api/plant-health/analyze` as `multipart/form-data`
- AI analysis result stored in history

## 🐛 Troubleshooting

### Backend won't start
```powershell
# Verify MySQL is running
Get-Service MySQL80

# Test DB connection
.\venv\Scripts\python.exe -c "from config import Config; print(Config.SQLALCHEMY_DATABASE_URI)"

# Check port 5000 is free
Get-NetTCPConnection -State Listen | Where-Object LocalPort -eq 5000
```

### Frontend can't reach backend
- Ensure backend is on `http://127.0.0.1:5000` (not 0.0.0.0)
- Check `vite.config.js` proxy target is `http://127.0.0.1:5000`
- Check browser DevTools Network tab for 4xx/5xx errors

### PowerShell MySQL import fails
```powershell
# Use Get-Content pipe (NOT < redirect — not supported in PowerShell)
Get-Content "database\schema.sql" -Raw | & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p"Password" phytopulse_db
```

### Plant health analysis returns 500
- Ensure `backend/uploads/` directory exists (created automatically on first run)
- Check `UPLOAD_FOLDER` in `.env` is set to `uploads`
